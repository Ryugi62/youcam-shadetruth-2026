ShadeTruth

The lipstick looked right on screen — but is it the shade the brand sells? ShadeTruth sends the brand's digital color to YouCam's makeup try-on, then measures how far the rendered lips drift from it (CIEDE2000) and shows a badge before the shopper buys.

How it is measured, and what it is not

  • Ground truth = the HEX we send (the brand's digital shade). Not the physical bottle, not your monitor.
  • Rendered area = pixels the try-on changed vs. the original photo, minus a 2px edge feather, highlights/shadows trimmed (10–90% lightness). A heuristic, not an API mask.
  • Drift = CIEDE2000 hue + chroma terms only; lightness L* is shown separately as lighter/darker, because matte shading and lighting legitimately change it.
  • Badge cut-offs (fixed before the first API call): ≤5 Matches · ≤10 Close · >10 Approximate preview.
  • Independent read-back: the rendered image is sent to YouCam's Face Tone Analyzer; its lip_color is compared to the brand HEX. "agree" = both readings within 4.
  • Limits: sample size is small, two model photos; two finishes (matte, gloss; intensity 100, skin smoothing off) — gloss drift includes the finish's intended highlights. Cosmetic use only — no skin diagnosis.
